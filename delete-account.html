끼리톡 계정·데이터 삭제 요청

개발자:

앱에서 바로 탈퇴하기 (권장)

  1. 앱을 열고 아래쪽 더보기 탭으로 갑니다.
  2. 맨 아래 회원 탈퇴를 누릅니다.
  3. 보낸 메시지·사진·파일도 지울지 고른 뒤, "탈퇴"를 입력하고 탈퇴하기를 누릅니다.

가입 승인을 기다리는 중이라면 첫 화면의 가입 취소 (회원 탈퇴)를 누르면 됩니다.

앱을 쓸 수 없을 때 이메일로 요청하기

이용 정지 등으로 로그인할 수 없거나 앱을 지운 경우, 아래 주소로 이메일을 보내 주세요. 앱을 다시 설치하지 않아도 됩니다.

  • 받는 사람:
  • 제목: [끼리톡] 계정 삭제 요청
  • 내용: 가입한 아이디, 보낸 메시지도 지울지 여부

가입 아이디와 이름(등록했다면 휴대폰 번호)으로 본인을 확인한 뒤 10일 이내에 삭제하고 결과를 회신합니다.

삭제되는 데이터

  • 계정(아이디·비밀번호), 프로필(이름·사진·상태메시지)과 프로필 사진 파일, 휴대폰 번호
  • 친구·차단 목록, 대화방 참여 정보, 알림 구독 정보, 초대 링크
  • 선택한 경우: 내가 보낸 메시지·사진·파일 전부

남는 데이터

  • 메시지 삭제를 선택하지 않은 경우, 이미 보낸 메시지는 상대방 대화방에 보낸 사람이 "(알 수 없음)"으로 표시되어 남습니다 (대화방 참여자가 모두 나가면 삭제).
  • 신고 기록(신고된 메시지 내용 포함)은 분쟁 대응을 위해 처리 후 1년간 보관한 뒤 삭제합니다.
