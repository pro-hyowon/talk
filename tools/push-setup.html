미니톡 알림 설정 도구

앱을 닫아도 새 메시지 알림이 오도록 필요한 키와 설정을 만들어 줍니다. 모든 값은 이 컴퓨터 안에서만 만들어지고 어디에도 전송되지 않습니다.

1데이터베이스 설정 (SQL Editor)

Supabase → SQL Editor → New query 에 아래 내용을 전부 붙여넣고 Run. (기본 설정인 schema.sql 을 먼저 실행해 둔 상태여야 합니다.)

2알림 발송 함수 만들기 (Edge Functions)

  1. Supabase → Edge Functions → Deploy a new function → Via Editor
  2. 함수 이름을 정확히 send-push 로 입력하고, 편집기 내용을 지운 뒤 아래 코드를 붙여넣고 Deploy
  3. 배포된 함수 → Details(설정) 에서 Verify JWT(JWT 검증) 를 끄고 저장

3함수 비밀값 등록 (Edge Functions → Secrets)

아래 4개를 이름과 값 그대로 추가하고 저장합니다.

4앱 설정 파일 수정 (js/config.js)

VAPID_PUBLIC_KEY: '', 줄을 아래 줄로 바꾸고 GitHub에 다시 올립니다.

5휴대폰에서 알림 켜기

앱을 새로고침(또는 다시 열기)한 뒤 더보기 → 새 메시지 알림을 눌러 허용합니다. 아이폰은 홈 화면에 추가한 앱에서만 가능합니다(iOS 16.4 이상).

보관 주의 — VAPID_PRIVATE_KEY 와 PUSH_WEBHOOK_SECRET 은 비밀번호처럼 다른 사람에게 보여 주지 마세요. 이 페이지를 닫으면 값은 사라집니다. 나중에 다시 만들면 기존 사용자는 앱을 한 번 열기만 하면 자동으로 다시 등록됩니다.
