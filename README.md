# 미니톡 설치 가이드

카카오톡처럼 쓰는 간단한 메신저 웹앱(PWA)입니다. 휴대폰 홈 화면에 설치해서 앱처럼 쓸 수 있고, 서버는 Supabase 무료 플랜, 호스팅은 GitHub Pages(무료)를 사용합니다.

## 주요 기능

- 아이디·비밀번호 회원가입 / 로그인, 비밀번호 변경
- 친구 추가(아이디 또는 휴대폰 번호로 검색), 친구 삭제, 프로필 사진·이름·상태메시지
- **친구 초대 링크·QR**: 내 링크를 카톡·문자로 보내거나 QR을 보여 주면, 상대가 누르는(찍는) 순간 바로 서로 친구 — 아직 가입 안 한 사람도 가입하자마자 친구가 됨
- **연락처로 친구 찾기 → 추천 친구**: 내 연락처의 휴대폰 번호와 일치하는 회원만 추천 (번호는 본인·관리자만 볼 수 있음). 고른 연락처마다 **회원인지·이미 친구인지·찾을 수 없는지** 바로 보여 주고, 그 자리에서 친구 추가
- **움직이는 이모티콘 24종**: 앱 아이콘의 말풍선 캐릭터 (안녕·고마워·사랑해·ㅋㅋㅋ 등). 새로 온 이모티콘은 3번 움직이고 멈추며, 누르면 다시 움직여요
- 서로 친구로 추가한 사람끼리만 대화 가능 (모르는 사람의 메시지는 오지 않음)
- 1:1 채팅, 단체 채팅(방 이름, 초대, 나가기) — 채팅 목록에서 **전체 / 1:1 / 단체** 로 나눠 보기
- 1:1 대화방에서 친구를 더 초대하면 **새 단체방**으로 만들어짐
- 단체방 **방장** 표시, 방장(또는 관리자)의 **내보내기** — 방장이 나가면 가장 먼저 들어온 사람이 방장이 됨
- **친구 요청 알림**: 누가 나를 친구로 추가하면 알림이 오고, 친구 탭 **받은 친구 요청**에서 수락하거나 숨길 수 있음
- 실시간 메시지 수신, 읽지 않은 사람 수 표시(카카오톡의 숫자 1), 안 읽은 메시지 배지
- 사진 전송(자동으로 용량 줄여서 전송), 사진 크게 보기
- **+ 버튼으로 보내기**: 앨범 사진, **카메라로 바로 찍어 보내기**, **파일**(문서·압축 등 한 개 20MB까지), **연락처**(이름·전화번호 카드 — 받은 사람은 전화·문자·연락처 저장)
- **답장**: 메시지를 옆으로 밀면(상대 글은 오른쪽, 내 글은 왼쪽) 바로 답장 — 답장에는 원본이 함께 보이고, 누르면 원본으로 이동
- **공감**: 메시지를 길게 누르면 ❤️ 👍 😂 😮 😢 ✅ 중 하나로 바로 공감 — 말풍선 아래에 개수가 보이고, 누가 눌렀는지도 확인
- **대화 기록 보호**: 방에서 나갔다가 다시 들어오거나 나중에 초대된 사람은 들어온 뒤의 대화만 보임 (사진·파일·공감 포함). 마지막 사람이 나가면 대화·사진·파일이 서버에서 모두 삭제
- **보낸 메시지 삭제**: 내 메시지를 길게 누르면(PC는 오른쪽 클릭) 삭제 — 그 자리에 ‘삭제된 메시지예요’ 가 남고, 상대 화면에서도 바로 바뀜 (글·사진·이모티콘 모두)
- 링크 자동 연결, 날짜 구분선, 이전 대화 불러오기
- 전송 실패 시 다시 보내기, 인터넷 끊김 표시, 재연결 시 놓친 메시지 자동 수신
- 홈 화면 설치(PWA), **앱을 닫아도 오는 새 메시지 알림(Web Push)** — 7단계 설정 시
- **관리자 화면**: 회원 관리, 가입 승인제, 이용 정지, 비밀번호 초기화, 강제 탈퇴, 전체 공지, **회원끼리 친구 연결**

## 설치 순서 (약 15분)

### 1단계. Supabase 프로젝트 만들기

1. https://supabase.com 에 가입하고 **New project** 를 누릅니다.
2. 프로젝트 이름과 DB 비밀번호를 입력하고, Region은 **Northeast Asia (Seoul)** 을 선택합니다.
3. 프로젝트가 만들어질 때까지 1~2분 기다립니다.

### 2단계. 데이터베이스 설정 (SQL 한 번 실행)

1. 왼쪽 메뉴 **SQL Editor** → **New query** 를 엽니다.
2. `supabase/schema.sql` 파일 내용을 전부 복사해서 붙여넣고 **Run** 을 누릅니다.
3. `Success. No rows returned` 가 나오면 완료입니다. (여러 번 실행해도 안전합니다.)

### 3단계. 로그인 설정 — 꼭 해야 합니다

1. 왼쪽 메뉴 **Authentication** → **Sign In / Providers**(또는 Providers) → **Email** 을 엽니다.
2. **Confirm email** 을 **끕니다(OFF)** 하고 저장합니다.
   - 이 앱은 아이디로 로그인하기 때문에 확인 메일을 보내지 않습니다. 켜져 있으면 회원가입이 되지 않습니다.
3. 같은 화면에서 **Allow new users to sign up** 이 켜져 있는지 확인합니다.

### 4단계. 연결 정보를 앱에 입력

1. **Project Settings** → **API Keys**(또는 Data API) 에서 다음 두 값을 복사합니다.
   - **Project URL** (예: `https://abcdefghij.supabase.co`)
   - **Publishable key**(`sb_publishable_…`) 또는 **anon public** 키(`eyJ…`)
2. `js/config.js` 파일을 메모장으로 열어 아래 두 줄을 바꾸고 저장합니다.

```js
SUPABASE_URL: 'https://abcdefghij.supabase.co',
SUPABASE_ANON_KEY: 'sb_publishable_xxxxxxxx',
```

> ⚠️ `service_role` 또는 `secret` 키는 절대 넣지 마세요. 공개 키(anon/publishable)는 웹에 노출되어도 괜찮도록 데이터베이스에 보안 정책(RLS)이 걸려 있어, 본인이 참여한 대화만 볼 수 있습니다.

### 5단계. GitHub Pages로 배포

1. GitHub에서 **New repository** → 이름 예: `minitalk` → **Public** 으로 만듭니다.
2. **Add file → Upload files** 로 이 폴더 안의 파일과 폴더를 **전부** 끌어다 놓고 **Commit changes** 를 누릅니다.
   - `index.html` 이 저장소 맨 위(루트)에 있어야 합니다.
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → **Save**.
4. 1~2분 뒤 `https://내아이디.github.io/minitalk/` 주소로 접속하면 앱이 열립니다.

> 저장소를 비공개로 두고 싶다면 GitHub Pages 대신 **Vercel**(무료)을 쓰면 됩니다. vercel.com 에서 GitHub로 로그인 → Add New → Project → 저장소 선택 → Deploy. 설정은 바꿀 필요 없습니다.

### 6단계. 휴대폰에 설치

- **안드로이드(크롬)**: 주소로 접속 → 오른쪽 위 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰(사파리)**: 주소로 접속 → 아래 공유 버튼 → **홈 화면에 추가**
- 설치 후 **더보기 → 새 메시지 알림** 을 눌러 알림을 허용하세요. (아이폰은 홈 화면에 추가한 앱에서만 알림이 가능합니다.)

### 7단계. 앱을 닫아도 오는 알림 켜기 (약 10분)

이 단계를 건너뛰어도 앱은 정상 동작하며, 그때는 앱이 열려 있을 때만 알림이 옵니다.

1. `tools/push-setup.html` 파일을 크롬(또는 엣지)으로 엽니다. (파일을 더블클릭하면 됩니다.)
2. Supabase Project URL과 관리자 이메일을 넣고 **설정값 만들기**를 누릅니다. 화면에 나오는 순서대로 진행합니다.
   1. 만들어진 **SQL**을 복사해 SQL Editor에서 실행합니다.
   2. **Edge Functions → Deploy a new function → Via Editor** 에서 이름을 `send-push` 로 하고, 도구가 보여 주는 **함수 코드**를 붙여넣어 배포합니다. 배포 후 함수 설정에서 **Verify JWT**(JWT 검증)를 **끕니다.**
   3. **Edge Functions → Secrets** 에 도구가 만든 비밀값 4개(`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `PUSH_WEBHOOK_SECRET`)를 등록합니다.
   4. `js/config.js` 의 `VAPID_PUBLIC_KEY: '',` 줄을 도구가 만든 줄로 바꿔 GitHub에 다시 올립니다.
3. 각 사용자가 앱에서 **더보기 → 새 메시지 알림**을 눌러 허용하면 끝입니다. 한 번 허용하면 이후 로그인할 때마다 자동으로 다시 등록됩니다.

알아둘 점
- 같은 사람이 휴대폰과 PC에서 각각 켜면 두 기기 모두 알림을 받습니다. 로그아웃하면 그 기기로는 알림이 오지 않습니다.
- 앱 화면을 보고 있을 때는 시스템 알림 대신 앱 위쪽에 알림이 뜹니다. (아이폰은 규정상 시스템 알림도 함께 뜹니다.)
- 알림 내용은 기기에서만 풀 수 있게 암호화되어 전송됩니다. 내용을 아예 숨기고 싶으면 도구에서 "메시지 내용 보여 주기"를 끄고 만든 SQL을 다시 실행하세요.
- 알림이 오지 않으면: Supabase → Edge Functions → send-push → **Logs** 에서 오류를 확인하고, 휴대폰 설정에서 브라우저/앱 알림이 허용되어 있는지 확인하세요. 아이폰은 iOS 16.4 이상, 홈 화면에 추가한 앱에서만 됩니다.
- `tools` 폴더는 설정용이라 GitHub에 올리지 않아도 됩니다.

## 사용 방법

1. 회원가입: 아이디(영문 소문자·숫자·_ 3~20자), 이름, 비밀번호(6자 이상), 휴대폰 번호(선택)
2. 친구 찾기
   - **초대 링크·QR (가장 쉬움)**: 친구 탭 → **친구 초대 링크·QR** → **링크 보내기**(카톡·문자 등으로 전송) 또는 화면의 QR을 상대 휴대폰 카메라로 찍게 하기. 상대가 링크를 열고 **친구 추가**를 누르면 바로 **서로 친구**가 돼서 곧바로 대화할 수 있어요. 상대가 아직 회원이 아니면 링크를 열어 가입하는 즉시 친구 추가 화면이 떠요. 내 링크로 누가 친구가 되면 알림이 와요.
     - 링크가 원치 않는 사람에게 퍼졌다면 같은 화면의 **새 링크 만들기** → 예전 링크·QR은 더 이상 쓸 수 없어요. (이미 친구가 된 사람은 그대로)
   - 아래 두 방법은 **상대방도 나를 친구로 추가해야** 대화할 수 있어요.
   - **연락처로 친구 찾기** (친구 탭 맨 위): 내 연락처의 번호와 일치하는 회원이 **추천 친구** 에 나와요. [추가] 를 누르면 친구가 되고, [×] 로 추천을 숨길 수 있어요.
     - 안드로이드(크롬): ‘연락처에서 고르기’ 로 찾을 사람을 고르면 끝. 고른 사람이 바로 목록으로 나오고, 사람마다 **추가 버튼(회원) / 친구(이미 친구) / 찾을 수 없어요** 가 표시돼요.
     - 찾을 수 없는 사람은 가입하지 않았거나, 휴대폰 번호를 등록하지 않았거나, 번호 검색을 꺼 둔 사람이에요. 결과 화면의 **앱 주소 보내기** 로 초대할 수 있어요.
     - 아이폰·PC: 연락처 파일(.vcf)을 불러와요. 아이폰은 ‘연락처’ 앱 → 왼쪽 위 **목록** → **모든 연락처** 길게 누르기 → **내보내기** → **파일에 저장** 한 뒤, 앱에서 ‘연락처 파일 불러오기’ 로 고르면 돼요. (웹앱은 휴대폰 연락처를 몰래 읽을 수 없어서, 사용자가 직접 고르거나 파일을 줘야 해요.)
   - **검색** (친구 탭 오른쪽 위 버튼): 아이디 또는 휴대폰 번호를 정확히 입력해서 찾아요.
3. 내 번호 관리: **더보기 → 휴대폰 번호** 에서 등록·변경·삭제, ‘번호로 나를 찾을 수 있게’ 끄기 (끄면 번호 검색과 연락처 추천에 내가 나오지 않아요)
4. 친구를 누르고 **1:1 채팅**, 또는 채팅 탭 오른쪽 위 버튼으로 여러 명을 골라 단체방 만들기
5. 이모티콘: 입력창 오른쪽 웃는 얼굴 버튼 → 이모티콘을 누르면 크게 움직이며 미리 보여 줘요 → 미리보기나 보내기 버튼을 누르면 전송. 최근 쓴 이모티콘은 맨 위에 모여요. 받은 이모티콘은 3번 움직이고 멈추고, 누르면 다시 움직여요. (휴대폰에서 '동작 줄이기'를 켜 둔 사람에게는 멈춘 그림으로 보여요.)
6. 채팅방 오른쪽 위 메뉴: 대화상대 보기, 초대(단체방), 채팅방 나가기
7. 사진·파일·연락처 보내기: 입력창 왼쪽 **+** 버튼 →
   - **앨범**: 사진첩에서 골라 보내기 (한 번에 10장까지)
   - **카메라**: 카메라가 바로 열려요. 찍으면 바로 전송돼요. (PC에서는 파일 고르기 창이 열려요)
   - **파일**: PDF·한글·엑셀·압축 파일 등 한 개 20MB까지, 한 번에 10개까지. 받은 사람은 파일을 누르면 원래 이름으로 내려받아요. 보안을 위해 실행 파일(.exe·.apk 등)은 보낼 수 없어요.
   - **연락처**: 이름과 전화번호를 입력하거나(안드로이드는 **휴대폰 연락처에서 고르기**) 보내면 카드로 가요. 받은 사람은 **전화·문자·저장** 버튼을 쓸 수 있어요. 저장을 누르면 연락처 파일(.vcf)이 내려받아지고, 열면 휴대폰 연락처에 추가돼요.
8. 답장: 답장할 메시지를 **옆으로 밀기** (상대 글은 오른쪽으로, 내 글은 왼쪽으로) → 입력창 위에 ‘○○님에게 답장’ 이 뜨면 글을 써서 보내요. 길게 눌러 **답장** 을 골라도 돼요. 취소는 ✕.
   - 답장 말풍선 위쪽의 원본을 누르면 원래 메시지로 이동해요.
9. 공감: 메시지를 **길게 누르기** (PC는 오른쪽 클릭) → 맨 위의 ❤️ 👍 😂 😮 😢 ✅ 중 하나를 눌러요.
   - 한 메시지에 한 사람당 하나예요. 다른 걸 누르면 바뀌고, 같은 걸 다시 누르면 취소돼요.
   - 말풍선 아래의 공감 표시를 눌러도 같은 공감이 추가·취소돼요. 길게 누르면 누가 눌렀는지 보여요.
   - 공감은 알림을 보내지 않아요.
10. 방 나가기와 대화 기록 (채팅방 오른쪽 위 메뉴 → 채팅방 나가기)
   - 나갔다가 다시 들어오면(1:1 방에서 상대가 새 메시지를 보낸 경우, 단체방에 다시 초대된 경우) **다시 들어온 뒤의 대화만** 보여요. 나중에 단체방에 초대된 사람도 초대된 뒤의 대화만 보여요. (공지사항 방은 지난 공지도 모두 보여요)
   - **마지막 사람까지 나가면** 그 방의 대화·공감·사진·파일이 서버에서 모두 삭제돼요. 되돌릴 수 없어요.
   - 관리자가 회원을 탈퇴시켜 아무도 없게 된 방의 사진·파일도 자동으로 정리돼요. 혹시 남은 파일이 있으면 **회원 관리 → 남은 사진·파일 정리** 로 지울 수 있어요.
11. 메시지 삭제: 내가 보낸 메시지를 **길게 누르기**(PC는 오른쪽 클릭) → **삭제**. 그 자리에 ‘삭제된 메시지예요’ 가 남아요. 글은 **복사** 도 할 수 있어요.
   - 내가 보낸 것만 지울 수 있고, 지운 내용은 되돌릴 수 없어요. 사진은 서버의 파일까지 지워져요.
   - 이미 상대 휴대폰에 떠 있는 알림 문구까지는 지울 수 없어요.

### 휴대폰 번호와 개인정보

- 휴대폰 번호는 본인과 관리자만 볼 수 있고, 다른 회원에게는 절대 보이지 않아요. 검색 결과에도 이름·아이디만 나와요.
- 연락처로 친구를 찾을 때 연락처의 번호는 일치 여부 확인에만 쓰이고 저장되지 않아요. 일치한 회원에 대해서만 "내 연락처에 저장된 이름"이 추천 목록 표시용으로 남아요.
- 다른 사람 번호를 무작위로 넣어 보는 것을 막으려고, 번호 확인은 한 사람당 하루 3,000건까지예요.
- 문자 인증이 없어서(무료 구성) 다른 사람 번호를 등록할 수도 있어요. 한 번호는 한 계정에만 등록되니, "이미 다른 계정에 등록된 번호" 라고 나오면 관리자가 **회원 관리 → 회원 → 휴대폰 번호 삭제** 로 풀어 주세요.

## 관리자 기능

### 관리자 지정하기 (처음 한 번)

1. 앱에서 내 아이디로 **먼저 회원가입**합니다.
2. Supabase **SQL Editor** 에 아래 한 줄을 붙여넣고, `내아이디` 를 실제 아이디로 바꿔 **Run** 합니다.

```sql
update public.profiles set is_admin = true, status = 'active' where username = lower('내아이디');
```

3. 앱을 새로고침하면 **더보기** 아래에 **관리자** 메뉴가 생깁니다. 다른 사람을 관리자로 지정하는 것은 이후 앱에서 할 수 있습니다.

### 앱에서 할 수 있는 것 (더보기 → 회원 관리)

| 기능 | 설명 |
|---|---|
| 회원 목록·검색 | 아이디·이름·휴대폰 번호 검색, 전체 / 승인 대기 / 정지 / 관리자로 나눠 보기, 가입일·최근 접속·친구 수·대화방 수 |
| 가입 승인제 | 켜면 새로 가입한 사람은 **승인 대기** 상태가 되고, 관리자가 승인해야 사용할 수 있습니다. 끄면 가입 즉시 사용. |
| 가입 승인 | 승인 대기 회원을 눌러 **가입 승인** |
| 이용 정지 / 해제 | 정지하면 즉시 대화를 볼 수 없고 다시 로그인할 수 없습니다. 언제든 해제 가능. |
| 비밀번호 초기화 | 8자리 임시 비밀번호가 화면에 나옵니다. 회원에게 전달하고, 로그인 후 더보기 → 비밀번호 변경으로 바꾸도록 안내하세요. |
| 관리자 지정 / 해제 | 여러 명이 함께 관리할 수 있습니다. 내 관리자 권한은 스스로 해제할 수 없습니다. |
| 친구 연결 | 회원을 누르고 **친구 연결** → 연결할 회원을 여러 명 골라 **서로 친구**로 바로 연결합니다. 양쪽 모두 친구 요청 없이 바로 대화할 수 있고, 두 사람 모두에게 "관리자가 ○○님과 친구로 연결해 줬어요" 알림이 갑니다. 이미 친구인 사람은 표시만 되고, 한쪽만 추가한 상태면 나머지 한쪽을 채워 줍니다. (이용 중인 회원만, 한 번에 200명까지) |
| 남은 사진·파일 정리 | 없어진 대화방에 남아 있는 사진·파일을 저장 공간에서 지웁니다. |
| 휴대폰 번호 확인·삭제 | 회원 정보에서 등록된 번호를 보고, 잘못 등록된 번호를 지울 수 있습니다. |
| 강제 탈퇴 | 계정과 친구·대화방 참여 정보가 삭제됩니다. 보낸 메시지는 "(알 수 없음)"으로 남습니다. 되돌릴 수 없습니다. |
| 전체 공지 | 모든 회원의 채팅 목록에 **공지사항** 방이 생기고 공지가 올라갑니다. 회원은 읽기만 가능하고 나갈 수 없습니다. 알림을 켠 회원에게는 알림이 갑니다. |

관리자도 앱에서는 다른 사람의 대화 내용을 볼 수 없습니다. 다만 Supabase 대시보드(Table Editor → `messages`)에 접속할 수 있는 사람은 볼 수 있으니, 대시보드 계정은 꼭 필요한 사람만 갖도록 관리하세요.

### 대시보드로 직접 할 때

- 회원 목록: Table Editor → `profiles`
- 신규 가입 자체를 막기: Authentication → Sign In / Providers → **Allow new users to sign up** 끄기
- 관리자를 모두 잃었을 때: 위의 "관리자 지정하기" SQL을 다시 실행

## 많이 접속할 때 (속도)

v1.6에서 접속자가 많아도 느려지지 않도록 다음을 바꿨어요.

- **실시간 전달**: 예전에는 메시지 1건마다 서버가 접속자 *전원*의 권한을 하나씩 확인했어요(접속자 200명이면 200번). 이제는 그 방 참여자에게만 바로 보내요(1:1이면 2건).
- **읽음 숫자(1)**: 20명 이하 방은 실시간, 21명 이상 방은 보고 있는 동안 5초마다 확인해요. 큰 방에서 실시간 전송량이 폭증하는 것을 막아요.
- **채팅 목록**: 새 메시지가 오면 서버에 다시 묻지 않고 바로 고쳐요. 바뀐 줄만 다시 그리고, 몰려 오면 0.2초에 한 번만 그려요.
- **채팅방 화면**: 새 메시지만 추가로 그리고, 몰려 오면 0.12초씩 모아서 그려요. 오래 켜 둔 방은 화면에 300개까지만 두고 나머지는 위로 올릴 때 불러와요.
- **데이터베이스**: 회원 삭제·정리용 인덱스 추가, 이미 읽은 방은 다시 쓰지 않기, 목록의 참여자 미리보기는 4명까지만.
- 놓친 실시간 알림이 있어도 앱이 켜져 있으면 90초마다 한 번 맞춰요.

측정 결과 (저사양 휴대폰처럼 CPU를 4배 느리게 한 상태, 메시지 100개를 2.5초 동안 받음)

| 상황 | v1.5 | v1.6 |
|---|---|---|
| 단체방(메시지 300개)을 보는 중 — 화면이 멈춘 시간 합계 | 약 18초 | 약 0.2초 |
| 채팅 목록을 보는 중 — 화면이 멈춘 시간 합계 | 약 0.4초 | 약 0.05초 |
| 그동안 채팅 목록을 서버에서 다시 불러온 횟수 | 40번 | 0번 |
| 회원 2,000명·메시지 10만 건에서 회원 1명 삭제 | 25ms | 6.5ms |

**무료 플랜의 한도** (2026년 10월 Supabase 공식 안내 기준)

- 실시간 **동시 접속 200명**, 실시간 전송 **초당 100건**(월 200만 건).
- 실시간 전송은 "받는 사람 수"만큼 세요. 30명 방에 메시지 1건 = 30건. 그래서 큰 단체방에서 대화가 아주 활발하면 초당 100건에 걸릴 수 있어요.
- 한도를 넘으면 실시간 전달이 잠시 늦어질 수 있지만, 메시지 자체는 저장되고 앱이 다시 맞춰서 보여 줘요.
- 그 이상이 필요하면 Pro 플랜(월 25달러부터)으로 올리면 동시 접속 500명·초당 500건이 되고, 설정에서 더 늘릴 수 있어요.

## 무료 플랜에서 알아둘 점

- 데이터베이스 500MB, 사진·파일 저장 공간 1GB, 동시 접속 약 200명 수준까지 무료입니다. 텍스트 위주라면 소규모 팀이 오래 쓸 수 있는 용량이고, 사진은 자동으로 줄여서(장당 약 200~500KB) 올라갑니다.
- 파일은 줄이지 않고 그대로 올라가서 저장 공간을 빨리 씁니다. 사용량은 Supabase **Storage** 메뉴에서 볼 수 있고, 필요 없는 파일은 보낸 사람이 메시지를 삭제하면 저장 공간에서도 지워집니다.
- **7일 동안 아무도 쓰지 않으면 프로젝트가 일시정지**됩니다. Supabase 대시보드에서 프로젝트를 열고 **Restore** 를 누르면 다시 켜집니다. 꾸준히 쓰면 정지되지 않습니다.
- 무료 플랜은 조직당 활성 프로젝트 2개까지 만들 수 있습니다.

## 현재 버전의 한계

- 7단계(알림 설정)를 하지 않으면 앱이 열려 있을 때만 알림이 옵니다.
- 휴대폰의 절전 모드·방해 금지 설정에 따라 알림이 늦거나 묶여서 올 수 있습니다.
- 음성·영상 통화, 메시지 수정, 동영상 촬영 전송은 포함되어 있지 않습니다. (동영상은 파일로 20MB까지 보낼 수 있어요)
- 비밀번호 찾기는 메일 발송이 없으므로 관리자가 앱에서 임시 비밀번호로 초기화해 줍니다.

## 수정·업데이트할 때

- 앱 이름: `js/config.js` 의 `APP_NAME`, 그리고 `index.html` 의 `<title>` 과 `manifest.webmanifest` 의 `name`
- 파일을 고쳐 GitHub에 다시 올리면 접속자에게 자동 반영됩니다. 설치된 앱에 바로 반영되지 않으면 `sw.js` 둘째 줄의 `minitalk-v1.14.0` 숫자를 올려서 함께 올리세요.
